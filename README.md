# Medikiosk
it's a platform that provides doctor and patient a great connectivity and platform to connect to each other, book appointments, take online consultancy and also doctor gets a clean record.

MediKiosk — Source Code

Files:
- index.html  — main webpage structure
- style.css   — complete UI styling
- app.js      — application logic, patient/doctor flows, localStorage, cases and responses

How to run:
1. Keep all three files in the same folder.
2. Open index.html in Chrome/Edge.
3. No Node.js, npm, server, or internet connection is required.

Prototype notes:
- Patient information is stored locally in the browser using localStorage.
- Doctor login accepts any non-empty demo password.
- The selected doctor only sees cases assigned to that doctor.
- This is a hackathon prototype, not a production medical system.
